# Where your web app goes

Put your `index.html` (the Quebame web app) in this repo root.

```
quebame/
├── index.html          ← Your app goes here
├── mcp-server/         ← MCP server (already set up)
├── README.md
└── ...
```

The MCP server and the web app are completely independent — the app runs in the browser, the server runs on your machine for AI integration.
